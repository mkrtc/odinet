# Product

## Register

product

## Users

Developers inspecting website traffic in Chromium DevTools and preparing website parsing workflows. The panel is used beside the inspected website, often docked into a narrow window.

## Product Purpose

Odinet exposes HTTP request data in a familiar Network workflow and provides an extensible foundation for future parsing tools. The popup provides a browser session log; the DevTools panel inspects the current page.

## Brand Personality

Precise, compact, familiar. User-facing copy supports English and Russian. Diagnostics are English.

## Anti-references

The requested reference is Chromium's native Network panel. Large dashboard cards, decorative headings, and marketing layouts do not serve this workflow.

## Design Principles

- Preserve the table, request selection and detail tab workflow of native Network.
- Show measured data and make missing data explicit.
- Add columns, detail views and data adapters through separate modules.
- Keep captured content inert and local to its intended lifetime.

## Accessibility & Inclusion

Use semantic tables, labelled controls, keyboard request selection, keyboard tabs and visible focus. Support English, Russian and the active DevTools color theme.
